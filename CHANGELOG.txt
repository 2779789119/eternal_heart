永恒之心 (Eternal Heart) 更新日志
=====================================

1.7.4 (2026-09-22)
------------------
[修复] 数值很大时配置面板输入框显示为空：
       根因 — 上一版为超大数值引入科学计数法显示（1E13 / 1.798E308），但输入框字符过滤器
         只允许数字与小数点，而 EditBox.setValue 在过滤器返回 false 时直接不赋值 →
         输入框空白（数值其实已保存成功，只是看不见）
       修复 — 过滤器改为允许科学计数法与符号中间态（1E13、1e-5、1.798E308、+3、-、.），
         与解析逻辑 Double.parseDouble 保持一致
[调整] 科学计数法阈值 1E7 → 1E9：1000000 这类常见数值仍按普通写法显示便于手工编辑，
       只有 10 亿以上才用紧凑写法

1.7.3 (2026-09-21)
------------------
[新增] 突破其它模组的限伤（战斗系统分类，2 项开关）：
       pierceDamageCap 突破单次伤害上限（默认开启）— 本模组加伤在 LivingHurtEvent 完成后
         记录期望伤害，等伤害走到最后一道 LivingDamageEvent（LOWEST，排在其它模组之后）
         时比对，被压到上限以下就恢复；只提升不压低（不影响其它模组的合法增伤）；
         只与同一 tick 的伤害配对（被无敌帧拦下时记录自动过期）。
         注意：期望值是护甲结算前的数值，开启后同时穿透目标护甲/抗性/吸收的减伤
       pierceImmunity 突破免伤 / 真实伤害（默认关闭）— 目标用「取消伤害事件」完全免疫时
         改用真实伤害直接扣血（跳过整条伤害管线）；覆盖 LivingDamageEvent 取消（免伤型）
         与 LivingAttackEvent 取消（BOSS 无敌阶段 / 闪避类模组，此时用增伤管线自行算一遍
         期望伤害再扣血）；仅对非玩家目标生效，开启后会连带无视不死图腾
[提示] 物品提示新增「突破其它模组的限伤」，配置项中英双语名称同步

1.7.2 (2026-09-21)
------------------
[变更] 配置下限全面放开（可以填负数）：所有数值项下限 → -Double.MAX_VALUE / Integer.MIN_VALUE，
       配置面板输入框本就允许负号（48 字符内），负数现在真实生效。负数语义：
         属性加成（攻击/攻速/生命/护甲/韧性/移速/幸运）→ 反向削弱自己
         伤害减免与各类抗性/受伤上限 → 放大承受的伤害
         摔落伤害保留 ≤0 → 完全免疫摔落
         反伤/溅射/光环伤害/额外打击 → 反过来治疗对方
         生命回复/击杀回血/生命窃取 → 持续掉血 / 击杀扣血 / 吸血变失血
         概率类（闪避/反射/点燃/斩杀/掉落保护…）→ 永不触发
         范围/间隔/时长类 → 关闭该功能，或按最频繁处理（间隔负 = 每 tick 一次）
         永怒层数/击杀叠层 → 层数恒为 0 / 负加成即掉层
         自动火把光照 → 永不放置火把；抢夺等级 → 按 0；爆炸威力 → 不产生爆炸
[加固] 负数专属保护：
       新增 Health 统一入口 — 负回复/负吸血无法走原版 heal()，只能 setHealth，
         而旁路改血会被「血量防篡改」回滚（表现为填负数没反应）；现在主动同步
         生命审计基线，负数真实生效
       抢夺等级钳制到 ≥0（负等级会让原版战利品表 nextInt(looting+1) 抛异常）
       击杀爆炸威力钳制到 ≥0（负半径对原版爆炸无意义）
       连锁挖掘上限改 long 计算（MIN_VALUE-1 会反向溢出成巨正值导致卡死，现钳制）
       掉落经验钳制到 ≥0（负倍率按 0 处理）

[新增] 防护机制（新配置分类「防护机制 (Aegis)」，共 9 项）：
       血量防篡改 healthGuard — 每 tick 审计生命值，只有走过伤害管线的掉血才被接受，
         旁路直接削血（被偷血/被强行改血）立即回滚；正常受伤/中毒/饥饿/虚空全部放行
       生命上限保护 maxHealthGuard — 佩戴瞬间记录上限基线，被削减时用补足修饰符补回，
         外部恢复后自动撤销、不叠加

         一击必杀，改为只扣到保留生命比例，并进入冷却（触发时动作栏提示+图腾音效）；
         /kill、虚空等无视无敌的伤害不受保护
       死亡保留物品/经验 keepInventory + keepExperience — 死亡时备份后立即清空物品栏与
         经验，使原版掉落流程无物可掉（掉落物不会被收走），重生时原样归还；
         备份同时写入持久化数据，死亡与重生之间服务器崩溃也不丢物品
       掉落物归属保护 itemGuard + itemGuardTicks — 自己丢出的物品保护期内只有本人能拾取
       物品提示新增金色防护行；中英文案同步

[重构] 战斗 — 额外打击冷却由「每击写目标实体 NBT」改为 fastutil 长整型表+惰性清理；
