永恒之心 (Eternal Heart) 更新日志
=====================================

1.2.3 (2026-07-03)
------------------
[修复] 属性系统重大修复 — 攻击伤害和攻击速度的 Operation
       从 MULTIPLY_BASE 改为 MULTIPLY_TOTAL：
       - MULTIPLY_BASE 只乘基础值（伤害 1.0、攻速 4.0），武器加成完全不受影响
       - 拿着钻石剑时实际增伤仅 +37.5%（而非期望的 +150%）
       - MULTIPLY_TOTAL 对最终值（含武器/工具加成）整体乘法
       - 现在 ×2.5 就是真正的 ×2.5 倍伤害和攻速
[修复] 无限箭矢 — 弓不再往背包塞幽灵箭：
       - 新增 ArrowLooseEvent 拦截 — 无实体箭时取消原版射箭，
         手动生成 Arrow 实体（含力量/冲击/火焰附魔，音效，耐久消耗）
       - 弩保留幽灵箭系统（1.20.1 无弩装弹事件可拦截）
       - 有真实箭矢或无限附魔时交给原版处理
       - 手动生成的箭设为 CREATIVE_ONLY 拾取模式（防止复制）
[修复] 配置注释更新 — 攻击伤害/速度注释从 "MULTIPLY_BASE" 
       改为 "Total 乘数" 语义，准确反映 MULTIPLY_TOTAL 行为

1.2.2 (2026-07-03)
------------------
[性能] 负面效果缓存 — clearNegativeEffects + onEffectApplicable
       使用静态 Set 缓存黑白名单，避免每次调用 new HashSet(configList)
[性能] 自动喝药优化 — PRIORITY_EFFECTS 提取为静态常量，
       消除每次调用 Set.of() 分配
[性能] 矿石判定优化 — FORGE_ORES_TAG 预缓存为静态 TagKey，
       直接 is(FORGE_ORES_TAG) 替代 8+ 个独立 ore 标签检查
[性能] 自动钓鱼优化 — 水域检测结果缓存 20 tick，避免每 interval
       扫描 5x5x3 区域；战利品表 ResourceLocation 静态缓存
[性能] 自动门优化 — 使用平方距离比较 (1.5²=2.25, 2.5²=6.25)，
       避免 Math.sqrt() 调用
[性能] 生长光环优化 — 补种搜索使用预计算 REPLANT_OFFSETS 数组，
       避免 BlockPos.betweenClosed 创建大量临时对象
[改进] 自动开箱优化 — 跳过 isEmpty() 容器 + 每周期最多取 5 堆，
       防止清空大型存储系统
[改进] 海豚恩惠去重 —移除 applyDolphinsGrace 中重复的
       WATER_BREATHING 效果（已在 applyPassiveEffects 中统一处理）
[改进] 有益效果移除 — 使用 stream().filter().toList() 替代
       ArrayList 中间收集（onTargetHurt 的 BENEFICIAL_STRIP）

1.2.1 (2026-07-03)
------------------
[性能] 冶炼配方缓存 — processBlockDrops 使用 ConcurrentHashMap 缓存
       冶炼结果，首次查询后永久复用，大幅减少 RecipeManager 遍历
[性能] 火把槽位缓存 — applyAutoTorch 缓存上次找到的火把槽位，
       避免每 tick 扫描完整背包
[性能] 发光效果优化 — applyGlow/applyOreHighlight 通过 hasEffect
       跳过已发光实体，延长持续时间为 400 tick 减少重复添加
[性能] 被动效果优化 — applyPassiveEffects 从每 tick 改为每 100 tick
       刷新一次，延长持续时间为 1200 tick，减少对象创建 100 倍
[性能] 连锁挖掘优化 — veinMine 使用预计算 VEIN_NEIGHBORS 数组，
       避免 BlockPos.withinManhattan 每次 BFS 创建 26 个临时对象
[新增] 无限岩浆桶 — 新增 infiniteBucketLava 配置项，
       开启后副手空桶自动补充为岩浆桶
[改进] 冲刺重构 — 分离"按键松开时间"和"冷却时间"两个时间戳，
       消除状态 conflate 导致的边界误触发

1.2.0 (2026-07-03)
------------------
[重写] 无限箭矢改为幽灵箭系统：不再向背包塞真实箭矢，
       而是注入带 NBT 标签（eternal_heart_ghost）的幽灵箭。
       拉弓/装弩时幽灵箭自动出现在背包第一个空位，
       切换武器时自动清除。原版 getProjectile() 自然识别。
       同时支持弓与弩，创造模式自动跳过。
[重写] 自动上坡改用 setMaxUpStep() 属性：
       直接设置跨步高度 1.25f（原版默认 0.6f），
       彻底消除 teleportTo 抖动，行走跨越丝般顺滑。
[改进] Boss 检测新增 forge:bosses 实体标签检查：
       有标签 → 直接判为 Boss，无标签 → 兜底血量检查。
       适配所有声明了 boss 标签的模组生物。
[新增] 幽灵箭辅助方法：ensureGhostArrow/sweepGhostArrows/isGhostArrow
       三件套干净管理幽灵箭生命周期。
